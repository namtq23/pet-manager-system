# Milestone v1.0: Pet Photo Manager

**Status:** ✅ SHIPPED 2026-08-25

## Overview

Hệ thống web app dành cho **Bệnh Viện Thú Y Mỹ Đình** giúp bác sĩ lưu trữ, nhóm ảnh theo từng lần khám và tra cứu nhanh tiến trình điều trị của thú cưng bằng số điện thoại chủ nuôi, hỗ trợ so sánh ảnh Trước/Sau điều trị.

**Goal**: Khởi tạo cấu trúc dự án Flutter Web + Supabase (PostgreSQL BaaS), xây dựng luồng Đăng nhập và Quản lý phiên làm việc cho 5-15 bác sĩ.
**Plans**: 3 plans
- [x] 01-01-PLAN.md — Flutter Web Project Setup, Supabase Schema & Doctor Login Tracer
- [x] 01-02-PLAN.md — Session Listener, Doctor Profile & Password Management
- [x] 01-03-PLAN.md — Admin Role Authorization & Doctor Account Management

**Plans**: 3 plans
- [x] 02-01-PLAN.md — Supabase Schema Migration, Models & Repositories

## Milestone Summary

**Key Decisions:**
- Tech stack: Flutter Web + Supabase (PostgreSQL BaaS) — 1 codebase duy nhất, tích hợp sẵn Auth, Storage & RLS.
- Web app responsive (thay vì mobile native) cho truy cập tiện lợi từ trình duyệt điện thoại và máy tính.
- Tập trung vào quản lý ảnh & tra cứu nhanh tiến trình bệnh thay vì quá tải với hồ sơ bệnh án phức tạp.

**Issues Resolved:**
- Khắc phục các lỗi vỡ viền (Overflow) giao diện Responsive trên màn hình điện thoại (< 450px).
- Bổ sung xác nhận an toàn (AlertDialog) khi xóa Thú cưng, Lần khám và Ảnh lẻ.
