## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Flutter Client → Supabase Auth & Database | Public HTTPS / WebSocket connection to Supabase API endpoints |
| Supabase Auth → PostgreSQL RLS | Database queries executed under `auth.uid()` JWT claims subject to RLS policies |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Elevation of Privilege | Database Tables | critical | mitigate | PostgreSQL Row Level Security (RLS) enabled on all tables; direct SQL bypassed by `is_admin()` policies |
| T-01-02 | Information Disclosure | Login Form | medium | mitigate | Uniform error message ("Email hoặc mật khẩu không đúng") on failed logins |
| T-01-03 | Tampering | Session Tokens | critical | mitigate | Supabase Auth manages JWT signing key (HS256/RS256) & auto token refresh |
</threat_model>
