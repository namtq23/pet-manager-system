# Plan 02-02: State Management & UI Screens/Dialogs (Customer & Pet UI Layer)

**Phase:** 02 - Quản lý Khách hàng & Thú cưng (Customer & Pet Management)
**Requirement IDs:** CUST-01, CUST-02, CUST-03
**Target Architecture:** Flutter Web + Supabase (PostgreSQL BaaS)

---

## 🎯 Plan Goal
Xây dựng lớp Quản lý Trạng thái (Controllers/StateNotifiers) và Giao diện người dùng Responsive (Views & Dialogs) hỗ trợ Bác sĩ tra cứu nhanh chủ nuôi qua SĐT, xem chi tiết danh sách thú cưng và thực hiện các thao tác Thêm/Sửa hồ sơ nhanh chóng trong < 30 giây.

---

## ⚡ Task Breakdown

### Task 1: Controllers & State Notifiers (Riverpod)
- **Files:**
  - `frontend/lib/features/customer/controllers/customer_controller.dart`
  - `frontend/lib/features/customer/controllers/pet_controller.dart`
- **Actions:**
  1. Impl `CustomerController` (`StateNotifier<CustomerState>`): Quản lý trạng thái danh sách khách hàng, từ khóa tìm kiếm (search query), trạng thái loading/error.
  2. Impl `PetController`: Quản lý việc thêm/sửa/xóa thú cưng cho khách hàng đang chọn.

### Task 2: Views & Responsive UI Screens
- **Files:**
  - `frontend/lib/features/customer/views/customer_search_screen.dart`
  - `frontend/lib/features/customer/views/customer_detail_screen.dart`
- **Actions:**
  1. `CustomerSearchScreen`: Thanh tìm kiếm SĐT/Tên nổi bật ở đầu trang (với tính năng debounce tìm kiếm tự động). Hiển thị danh sách thẻ thông tin chủ nuôi + tóm tắt cún sở hữu. Trạng thái rỗng thân thiện khi không tìm thấy kết quả.
  2. `CustomerDetailScreen`: Hiển thị chi tiết thông tin chủ nuôi (Họ tên, SĐT, Địa chỉ, Ghi chú) và Grid/List các cún sở hữu với thông tin Giống, Tuổi, Cân nặng. Nút bấm "Thêm Thú cưng" và "Sửa Hồ sơ".

### Task 3: Form Dialog Modals
- **Files:**
  - `frontend/lib/features/customer/views/customer_form_dialog.dart`
  - `frontend/lib/features/customer/views/pet_form_dialog.dart`
- **Actions:**
  1. `CustomerFormDialog`: Dialog modal nhập Họ tên, SĐT (validate 10-11 số), Địa chỉ, Ghi chú. Xử lý hiển thị thông báo lỗi tiếng Việt nếu trùng SĐT.
  2. `PetFormDialog`: Dialog modal nhập Tên cún, Giống cún, Giới tính, Tuổi, Cân nặng (kg), Ghi chú sức khỏe.

---

## 🔍 Verification Criteria
1. Tìm kiếm SĐT phản hồi tức thì và cập nhật UI mượt mà.
2. Dialog form validate đầy đủ các trường bắt buộc, hiển thị lỗi tiếng Việt thân thiện khi ném exception.
3. Giữ quy tắc 30 dòng/hàm cho toàn bộ các file view & dialog.
